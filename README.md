# Kode-n-Rolla - Offensive Security Portfolio

Personal portfolio of **Pavel Egin (aka Kode-n-Rolla)**, a Penetration Tester and Offensive Security Specialist with 3+ years of experience in web application and API penetration testing, AWS security assessments, vulnerability research and security reporting.

**Think like an attacker. Report like a professional.**

I approach penetration testing as a structured investigation: mapping attack surfaces, forming hypotheses, validating vulnerabilities, understanding their impact and communicating actionable findings.

Alongside offensive security work, I develop security research tools using Rust, C# and Python.

**Live portfolio:** https://kode-n-rolla.github.io/

- **Web & API Penetration Testing** - black-, grey- and white-box testing, authentication and authorization, business logic vulnerabilities, vulnerability validation and proof-of-concept development.
- **Cloud & Infrastructure Security** - AWS security assessments, IAM permissions, S3 configurations, exposed services and network reconnaissance.
- **Security Research & Tooling** - custom tools, automation, secure code review and attack-surface analysis.

This website is a lightweight static application built with:

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

No frontend framework, build pipeline or paid hosting is required.

## Portfolio Maintenance

Website content is managed in **`site-data.js`**, independently of the HTML structure and CSS styles.

| Field | Purpose |
|---|---|
| `identity` | Professional headline, introduction and availability |
| `contact` | Email, LinkedIn, Telegram and GitHub |
| `services` | Offensive security expertise and technical skills |
| `projects` | Project descriptions, links and visibility |
| `about` | Professional background and testing methodology |
| `human` | Optional personal section |

To add a project, create a new entry in the `projects` array with a unique `id`.

Use `featured: true` to display it on the website or `featured: false` to keep it hidden.

## Local Development

Clone the repository:

```bash
git clone https://github.com/Kode-n-Rolla/Kode-n-Rolla.github.io.git
cd Kode-n-Rolla.github.io
```

Start a local server:

```bash
python -m http.server 8000
```

Open http://localhost:8000 in your browser.
